Требования к службам "Умный домофон" и "Умный шлагбаум".

# Требования безопасности

| №      | Требование                                                                                                                                                                                                                                                                                               | Комментарий                                                             |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| ИБ0001 | Сторонняя служба распознавания образов должна хранить личные данные в зашифрованном виде.<br>К личным данным относятся:<br>1. Фотография - биометрия для распознавания лица.<br>2. Номер транспортного средства.<br>3. Данные документов владельца транспортного средства.<br>4. Фамилия, Имя, Отчество. | По этому требованию будет подбираться соответствующая сторонняя служба. |
| ИБ0002 | Сторонняя служба распознавания образов не должна передавать события распознавания лиц и транспортных номеров, содержащие личные данные. Каждому физическому лицу и транспортному средству, принадлежащему физическому лицу, присваивается обезличенный номер.                                            |                                                                         |
| ИБ0003 | Сторонная служба распознавания образов принимает данные видеопотока в зашифрованном виде по протоколам на основе UDP, предназначенным для обработки видеопотоков.                                                                                                                                        |                                                                         |
| ИБ0004 | СКУД должна хранить обезличенные номера из службы распознавания образов                                                                                                                                                                                                                                  |                                                                         |
| ИБ0005 | Сторонняя служба распознавания образов должна соблюдать положения ФЗ152, в частности, реализовать обязательное "право на забвение".                                                                                                                                                                      |                                                                         |
| ИБ0006 | Сторонняя служба распознавания образов должна запрашивать разрешение на обработку личных данных.                                                                                                                                                                                                         |                                                                         |

| №      | Требование                                                                                                                                                                                      | Комментарий |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| ИБ0007 | Система компании PropDevelopment должна применять протокол авторизации и аутентификации OAuth2.0 для получения данных со стороны службы распознавания образов.                                  |             |
| ИБ0008 | Система компании PropDevelopment должна запрашивать у службы распознавания образов наименьшее количество данных, необходимых и достаточных для работы служб "Умный домофон" и "Умный шлагбаум". |             |

# Описание взаимодействия
1. Пользователь (собственник недвижимости, наниматель, жилец, гость) может регистрироваться в службе распознавания образов.
2. Пользователь (собственник недвижимости, наниматель, жилец, гость) может загрузить биометрические данные в службу распознавания образов.
3. Пользователь (собственник недвижимости, наниматель, жилец, гость) может добавить транспортное средство, подтверждая владение им через государственные службы (ГосУслуги).
4. Собственник недвижимости и наниматель могут сформировать в сервисах ЖКУ пригласительные ссылки, по которым могут добавляться новые гости, жильцы. Пригласительные ссылки пересылаются желаемому лицу.
5. Лицо, получившиее пригласительную ссылку, попадает на web-страницу, из которой происходит авторизация в службе распознавания образов, после чего приложение (или web-страница) службы распознавания образов запрашивает подтверждение на добавление лица или транспортного средства в список доверенных лиц для конкретной квартиры или двора (в случае транспортного средства).
6. Служба распознавания образов передаёт в СКУД обезличенный номер человека или транспортного средства при получении подтверждения.
7. СКУД запоминает полученный номер.
8. При срабатывании камеры домофона или камеры шлагбаума, служба работы с камерами запускает передачу видеопотока в службу распознавания образов.
9. Служба распознавания образов при успешном распознавании лица или номера транспортного средства передаёт в СКУД обезличенный идентификатор распознанного объекта в совокупности с данными по камере домофона или шлагбаума, с которых был захвачен видеопоток.
10. СКУД определяет, какие выданы доступы для данного обезличенного идентификатора и подаёт команду на соответствующее оборудование (открыть дверь или поднять шлагбаум).
