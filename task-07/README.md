Также приведённые фильтры для вычленения отдельных записей из журнала аудита
тоже не все правильные.

Пример:

```
jq 'select(.verb=="create" and .objectRef.subresource=="exec")' audit.log
```

В действительности же, работает такой фильтр:

```
jq 'select(.verb=="get" and .objectRef.subresource=="exec")' audit.log
```

Но чтобы это выяснить, пришлось потратить много времени, разобрать скрипт
симуляции инцидентов по отдельной команде и смотреть, какая команда какие
записи в журнале аудита генерирует. И то, действительно ли это правильная
команда? Может, на другой версии minikube это будет другой фильтр?
